## 💻 Como Instalar e Rodar em Outro Computador

Para abrir e rodar esta apresentação em outro computador (Windows, Mac ou Linux), siga o passo a passo simples abaixo:

### 1️⃣ Pré-requisito (Apenas uma vez)
Você precisa ter o **Node.js** instalado na máquina.
- Se ainda não tiver, baixe e instale a versão LTS gratuita em: **[https://nodejs.org](https://nodejs.org)**

---

### 2️⃣ Passo a Passo de Execução

1. **Descompacte o arquivo `.zip`** em qualquer pasta de sua preferência (ex: na sua área de trabalho ou Documentos).
2. **Abra o Terminal / Prompt de Comando (CMD ou PowerShell)** dentro da pasta descompactada.
   - *Dica no Windows*: Abra a pasta descompactada, clique na barra de endereço lá em cima, digite `cmd` e aperte `Enter`.
3. No terminal, digite o seguinte comando para instalar as dependências:
   ```bash
   npm install
   ```
4. Após o término da instalação, inicie a apresentação digitando:
   ```bash
   npm run dev
   ```
5. O terminal mostrará o link local (geralmente **`http://localhost:3000`** ou **`http://localhost:5173`**).  
   Basta clicar no link ou digitar no seu navegador Google Chrome, Edge ou Firefox para ver os slides funcionando!

---

### ⌨️ Atalhos de Navegação durante a Apresentação

| Tecla / Botão | Ação |
| :--- | :--- |
| `→` (Seta Direita) ou `Espaço` | Avançar para o próximo slide |
| `←` (Seta Esquerda) | Voltar para o slide anterior |
| `F` | Alternar modo **Tela Cheia (Fullscreen)** |
| `G` | Abrir a **Grade com os 33 slides** para pular para qualquer um |
| `Esc` | Fechar modal de visão geral |

---

### 📝 Como Editar o Conteúdo dos Slides
Todo o texto e perguntas dos 33 slides estão no arquivo:
📂 `src/data/slidesData.js`

Ao editar e salvar qualquer texto nesse arquivo, o navegador atualiza automaticamente em tempo real!
